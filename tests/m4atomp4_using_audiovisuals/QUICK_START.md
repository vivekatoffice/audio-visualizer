# Quick Start Guide - Audio Visualizer Studio

## 🚀 Get Started in 3 Minutes!

### Step 1: Open the Application (30 seconds)

**Option A: Direct File**
```
1. Navigate to the project folder
2. Double-click "index.html"
3. Opens in your default browser
```

**Option B: Local Server (Recommended)**
```bash
# In the project directory
npx serve -l 3000

# Then open: http://localhost:3000
```

---

### Step 2: Load Your Audio (30 seconds)

1. Click **"Choose Audio File"** button
2. Select your M4A, MP3, WAV, or OGG file
3. Wait for file info to appear

✅ **You should see**: `filename.m4a (X.XX MB)`

---

### Step 3: Customize (1 minute)

#### Choose a Visualization Style
Click one of these:
- 🌊 **Waveform** - Classic wave display
- ⭕ **Circular** - Radial frequency bars
- 📊 **Bars** - Traditional spectrum
- ✨ **Particles** - Dynamic particles
- 🌀 **Spiral** - Mesmerizing spiral
- 💫 **Radial** - Burst pattern

#### Pick a Color Scheme
Click one of the 6 gradient boxes:
- **Purple Dream** (default)
- **Pink Passion**
- **Ocean Blue**
- **Mint Fresh**
- **Sunset Glow**
- **Deep Ocean**

#### Adjust Settings (Optional)
- **Smoothing**: 0.8 (recommended)
- **Sensitivity**: 1.0 (recommended)

---

### Step 4: Play & Enjoy (30 seconds)

1. Click **▶️ Play** button
2. Watch the visualization come to life!
3. Use **⏸️ Pause** or **⏹️ Stop** as needed

---

### Step 5: Export Video (Optional)

1. Click **"Export to MP4"** button
2. Audio plays automatically
3. Recording indicator shows: 🔴 Recording...
4. Wait for audio to finish
5. Video downloads automatically!

📹 **Output**: `audio_visualization_[timestamp].webm`

---

## 🎯 Quick Tips

### For Best Results

✅ **DO:**
- Use high-quality audio files
- Try different visualization + color combinations
- Adjust sensitivity for your music type
- Let export complete fully

❌ **DON'T:**
- Switch tabs during export
- Use very large files (>100MB)
- Minimize browser during recording
- Interrupt the export process

## 🔧 Troubleshooting

### Problem: Export Failed

**Quick Fix:**
```
1. Refresh the page (F5)
2. Load audio file again
3. Click Export again
4. Check browser console (F12) for errors
```

### Problem: No Visualization

**Quick Fix:**
```
1. Make sure audio file is loaded
2. Click Play button
3. Check if audio is actually playing
4. Try a different audio file
```

### Problem: Choppy Animation

**Quick Fix:**
```
1. Close other browser tabs
2. Close other applications
3. Try a smaller audio file
4. Lower sensitivity setting
```

## 💡 Pro Tips

### Tip 1: Test Before Exporting
Always play and preview your visualization before exporting to ensure it looks good.

### Tip 2: Experiment with Settings
Try different sensitivity values for different parts of your song. Bass-heavy sections may need higher sensitivity.

### Tip 3: Match Colors to Mood
- Energetic → Bright colors (Pink, Mint)
- Calm → Cool colors (Blue, Deep Ocean)
- Professional → Purple Dream

### Tip 4: Optimize File Size
Resize your browser window to a smaller size before exporting to reduce file size while maintaining quality.

### Tip 5: Batch Processing
Open multiple browser tabs to process multiple songs simultaneously (if your system can handle it).
